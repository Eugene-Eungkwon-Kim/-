## WP-3. kreri.re.kr/32 자료 수집 및 학습 데이터화

**[목표]** 지정 페이지의 자료를 재현 가능한 파이썬 스크립트로 수집하고, 용도에 맞는 학습 데이터 형식으로 정리한다.

**[현재 차단 요인]** 이 세션에서 해당 사이트가 403으로 차단됨. 자료 종류도 미확인. **먼저 §6의 질문에 답이 있어야 설계 가능**

**[대상]** 신규 `avm_project/scripts/collect_kreri.py` (예정), 산출물 `avm_project/data/raw/kreri/`, `.../processed/kreri/` (git 제외 경로)

**[설계: 자료 종류별 분기]**
| 자료 종류 | 수집 | 정리 결과 | 용도 |
|---|---|---|---|
| 통계표 (xls/csv, 시계열) | 다운로드 링크 수집 후 파일 저장 | 정규화된 CSV (기간, 지역코드, 지표, 값) | AVM 거시 피처 |
| 연구보고서 (PDF/HTML) | 목록·PDF 수집 | 문서 메타데이터 + 섹션별 텍스트 JSONL | 보고서 분석/검색 (기존 `evaluation-report-analysis/`의 추출·섹션분할 재사용 가능) |

**[공통 원칙]** (`CLAUDE.md` 저장소 전역 원칙)
- **파이썬 퍼스트**: 독립 실행 스크립트로 작성하고 반복 실행. AI는 최초 설계와 파서 수정에만 개입
- **오류 분류와 종료 코드**: 일시적(타임아웃/429/5xx)은 지수 백오프 재시도 후 건너뛰고 종료 코드 0, 인증(401/403)은 즉시 중단하고 2, 스키마/파싱 오류는 해당 단위만 건너뛰고 기록한 뒤 3. 참고 구현은 `fetch_realestate.py`와 `app/integrations/http_client.py`
- **재개 가능**: 이미 받은 파일은 건너뛰는 멱등 동작, 수집 매니페스트(URL, 수집일, 해시) 기록
- **예의**: 요청 간 지연, 식별 가능한 User-Agent, 동시 요청 제한

**[이용 조건 확인 (구현 전 필수)]**
- 사이트 이용약관·저작권 안내·`robots.txt` 확인. 연구보고서는 저작권이 있어 **내부 분석용인지, 모델 학습·재배포에 쓰이는지**에 따라 허용 범위가 다를 수 있음
- 이용 조건이 불명확하면 수집 전에 사용자(또는 사이트 운영기관)에게 확인

**[범위 제외]** 로그인이 필요한 영역 우회, 접근 차단(403) 우회 시도, 대량 병렬 수집

**[완료 기준]**
- [ ] 이용 조건 확인 기록
- [ ] 스크립트 1회 실행으로 전체 수집, 재실행 시 중복 다운로드 없음
- [ ] 파싱 실패 건수와 목록이 보고서에 남음 (종료 코드 규약 준수)
- [ ] 정리 결과의 스키마 문서와 샘플 10건
- [ ] 단위 테스트 (파서는 저장된 샘플 HTML/파일로, 네트워크 없이)

**[일정]** 추정 설계 0.5일 (자료 확인 후) + 구현·테스트 1~2일
**[의존]** §6 답변, PC 또는 접근 가능한 네트워크 환경에서의 최초 확인
