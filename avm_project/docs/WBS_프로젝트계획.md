# AVM 모델 개발 프로젝트 - WBS 및 상세 계획

**프로젝트 명:** Automated Valuation Model (AVM) 개발  
**시작 일자:** 2026-06-09  
**목표:** NPL 데이터 기반 AVM 모델 개발 및 실제 평가 적용

---

## 1. 프로젝트 개요 (Project Overview)

### 목표
- NPL(Non-Performing Loans) 폴더의 역사적 데이터를 활용한 자동감정가 모델 개발
- 모델의 실제 평가 시스템 통합 및 검증
- 평가 정확도 및 신뢰성 확보

### 범위
- 데이터 수집 및 전처리
- 모델 개발 및 학습
- 모델 검증 및 평가
- 실제 시스템 적용

- 데이터 품질 분석 및 문서화

**작업:**
| 작업 ID | 작업명 | 설명 | 예상 기간 | 담당 |
|--------|-------|------|---------|------|

## 7. 성공 기준

1. **데이터 정확도:** 전처리된 데이터 품질 지수 > 95%
2. **모델 성능:** R² > 0.85 (테스트 세트)
3. **예측 오차:** RMSE < 설정된 임계값
4. **시스템 안정성:** 99% 이상의 가용성
5. **문서화:** 모든 코드 및 절차 문서화 완료
