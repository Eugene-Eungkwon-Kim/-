## 📋 1. 프로젝트 개요

### 1.1 목표

**프로덕션급 자동감정가 모델(AVM) 엔진 구축**

Loan4U의 실제 운영 시스템(MASS - Multi-factor Automated Valuation System)을 벤치마크하여, 다음 기능을 갖춘 차세대 AVM 엔진 개발:

1. **3-모델 앙상블 예측**: XGBoost(80%), LightGBM(15%), GradientBoosting(5%)
2. **지역/유형별 보정값**: Loan4U 방식의 부동산유형×행정구역등급 매트릭스
3. **낙찰가 예상**: 경매 기준가 자동 계산 (Base × Region Rate × Market Factor)
4. **고신뢰도 검증**: 이상탐지, 신뢰도 구간, 공시가격 범위 확인
5. **극고속 인퍼런스**: NPU 최적화로 1-2ms 레이턴시 달성

### 1.2 핵심 특성

| 특성 | 목표값 | 구현 방식 |
|------|--------|---------|
| **레이턴시** | 1-2ms | NPU 최적화 + LRU 캐싱 (40% 히트율) |
| **신뢰도** | > 85% | 앙상블 + 이상탐지 + 신뢰도 구간 |
| **정확도** | R² > 0.84 | 3-모델 가중 평균 |
| **처리량** | 100+ req/sec | FastAPI 비동기 처리 |
| **메모리** | < 2GB | LRU 캐시 정책 + 모델 공유 |

## 📊 2. 비즈니스 가치

### 2.1 비용 절감

| 항목 | 이전 | 개선 | 절감 |
|------|------|------|------|
| **처리 시간/건** | 100ms | 2ms | **98% ↓** |
| **서버 전력** | RTX 3090 (320W) | NPU (45W) | **86% ↓** |
| **모델 크기** | 1.2GB | 300MB | **75% ↓** |
| **인프라 비용/월** | $1,000 | $200 | **80% ↓** |

### 2.2 성능 향상

- **단일 가치평가**: 100ms → 2ms (50배 빠름)
- **일일 처리량**: 864,000 → 43,200,000 건 (50배 증가)
- **동시 사용자**: 1 → 50명 (50배 확장)
- **서비스 가용성**: 99% → 99.5%+ (다중 모델 폴백)

### 2.3 경쟁 우위

1. **Loan4U 대비 우수성**
   - 3-모델 앙상블 vs 단일 Random Forest
   - 자동 신뢰도 계산 vs 고정값
   - 실시간 모니터링 vs 수동 관리

2. **시장 진입 가능성**
   - 낮은 인프라 비용 → 중소은행 진출 가능
   - 높은 처리량 → 대규모 포트폴리오 분석 가능
   - 초저지연 → API 기반 모바일 앱 지원
