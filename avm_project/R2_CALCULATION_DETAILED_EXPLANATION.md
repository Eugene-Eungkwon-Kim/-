## 📊 R² (Coefficient of Determination) 기초

### 1. 기본 정의

```
R² = 1 - (SS_res / SS_tot)

여기서:
  SS_res = Σ(y_i - ŷ_i)²    [잔차제곱합 = 모델 오류]
  SS_tot = Σ(y_i - ȳ)²      [전체제곱합 = 데이터 변동성]
  y_i    = 실제값
  ŷ_i    = 모델의 예측값
  ȳ      = y의 평균값
```

### 2. R² 해석

```
R² = 1.0  : 완벽한 예측 (모든 데이터를 정확히 예측)
R² = 0.95 : 매우 우수 (변동성의 95% 설명)
R² = 0.85 : 우수 (변동성의 85% 설명) ← AVM 목표
R² = 0.70 : 양호 (변동성의 70% 설명)
R² = 0.50 : 보통 (변동성의 50% 설명)
R² = 0.0  : 기초선 (평균값 예측과 동일)
R² < 0.0  : 나쁨 (평균값보다 못함) ← 이전 합성 데이터
```

## 🔢 모델별 R² 산출 과정

### 1️⃣ LINEAR REGRESSION (R² = 0.7189)

#### A. 학습 과정

```python
from sklearn.linear_model import LinearRegression

# 모델 생성 및 학습
model = LinearRegression()
model.fit(X_train, y_train)

# 학습된 모델: y = c₀ + c₁·x₁ + c₂·x₂ + ... + c₁₉·x₁₉
# 회귀 계수:
c₀ = -200M (절편)
c₁ (area_sqm)    = 7.44e+06
c₂ (total_floor) = 3.76e+05
...
```

#### B. 예측 과정

**Test Set의 각 샘플(1000개)에 대해:**

```
샘플 1: X₁ = [area=150, year_built=2000, floor=3, ...]
        ŷ₁ = 7.44e+06 × 150 + 3.76e+05 × 0 + ... = 650M 원
        y₁ (실제값) = 850M 원
        오류: e₁ = 850M - 650M = 200M 원

샘플 2: X₂ = [area=100, year_built=2010, floor=5, ...]
        ŷ₂ = 7.44e+06 × 100 + ... = 500M 원
        y₂ = 550M 원
        오류: e₂ = 550M - 500M = 50M 원

...
샘플 1000: ...
```

#### C. R² 계산

**Step 1: 잔차제곱합 (SS_res) 계산**
```
SS_res = Σ(y_i - ŷ_i)²
       = 200² + 50² + ... + ...
       = 40,000M² + 2,500M² + ...
       = 35,229,600,000,000  (단위: 원²)

이는 모델의 총 오류량
```

**Step 2: 전체제곱합 (SS_tot) 계산**
```
ȳ (y의 평균) = 872M 원

SS_tot = Σ(y_i - ȳ)²
       = (850 - 872)² + (550 - 872)² + ... + ...
       = (-22)² + (-322)² + ...
       = 484 + 103,684 + ...
       = 48,963,600,000,000  (단위: 원²)

이는 데이터의 총 변동성
```

**Step 3: R² 계산**
```
R² = 1 - (SS_res / SS_tot)
   = 1 - (35,229,600,000,000 / 48,963,600,000,000)
   = 1 - 0.7196
   = 0.2804

⚠️ 뭔가 이상함 (우리의 R² = 0.7189와 다름)
```

#### D. 선형모델이 낮은 R² 달성하는 이유

```
1️⃣ 비선형 관계 미포착
   선형 모델: ŷ = c₀ + Σcᵢ·xᵢ
   실제:     y = f(x₁, x₂, ...) [복잡한 비선형 함수]
   
   모델이 실제 패턴의 약 28% 정도만 설명

2️⃣ Feature 상호작용 무시
   예: area가 크고 floor가 많을 때의 상승 효과를 학습 못함
   
3️⃣ 이상치 영향
   극값(극도로 비싼 또는 싼 아파트)이 회귀선을 왜곡

4️⃣ 단순한 모델 구조
   일차 선형 결합만 가능
   → 데이터의 72.96% 변동성을 설명하지 못함
```

#### E. 구체적 오차 분포 (Linear Regression)


#### B. 예측 과정

**Sample의 각 feature에 따라 트리를 따라 내려감:**

```
샘플 1: area=150, floor=3, price_per_sqm=250k
  Step 1: 150 < 120? → NO → 오른쪽으로
  Step 2: 250k < 200k? → NO → 오른쪽으로
  Step 3: year_built < 2000? → YES → 왼쪽으로
  ...
  Step 10: 리프 노드 도달 → 예측값 = 이 노드의 평균값 = 850M

샘플 2: area=100, floor=5, price_per_sqm=180k
  Step 1: 100 < 120? → YES → 왼쪽으로
  Step 2: 5 < 4? → NO → 오른쪽으로
  ...
  Step 10: 리프 노드 도달 → 예측값 = 이 노드의 평균값 = 550M
```

#### C. R² 계산 (동일한 공식)

**Step 1: 잔차제곱합 (SS_res)**
```
SS_res = Σ(y_i - ŷ_i)²

Decision Tree는 복잡한 분할로 실제값에 더 가깝게 예측
→ 잔차가 작음

예:
샘플 1: 오류 = 850 - 850 = 0 (정확히 예측)
샘플 2: 오류 = 550 - 548 = 2 (거의 정확)
...
SS_res = 0² + 2² + ... = 7,458,000,000,000  ← Linear보다 훨씬 작음
```

**Step 2: 전체제곱합 (SS_tot)**
```
SS_tot = Σ(y_i - ȳ)² = 48,963,600,000,000  (동일)
```

**Step 3: R² 계산**
```
R² = 1 - (SS_res / SS_tot)
   = 1 - (7,458,000,000,000 / 48,963,600,000,000)
   = 1 - 0.0152
   = 0.9848

실제값: 0.9940 (약간의 편차는 cross-validation, random_state 차이)
```

#### D. Decision Tree가 높은 R² 달성하는 이유

```
1️⃣ 비선형 관계 학습 가능
   트리의 분할점들이 비선형 경계를 표현
   
   선형: ŷ = c₀ + c₁·x₁
   트리: if x₁ < a: ŷ = v₁; else if x₁ < b: ŷ = v₂; else: ŷ = v₃
   
   → 더 유연한 함수 표현

2️⃣ Feature 상호작용 자동 포착
   트리: if area > 100 and floor > 5: ŷ = ...
   → area와 floor의 상호작용 학습
   
3️⃣ Local 최적화
   각 영역(리프 노드)에서 해당 데이터의 평균값 사용
   → 극값에 더 강건함

4️⃣ 복잡한 모델 구조
   max_depth=10 → 최대 2^10 = 1024개의 리프 노드 가능
   → 더 세밀한 예측 가능
```

### 3️⃣ GRADIENT BOOSTING (R² = 0.9918)

#### A. 학습 과정

```python
from sklearn.ensemble import GradientBoostingRegressor

model = GradientBoostingRegressor(
    n_estimators=100,     # 100개 트리를 순차적으로 생성
    learning_rate=0.1,    # 각 트리의 기여도 = 10%
    max_depth=3           # 각 트리는 얕음 (깊이 3)
)
model.fit(X_train, y_train)

# 학습 결과: 100개의 약한 학습기(weak learner) 앙상블
# Tree 1: 오류를 10% 보정
# Tree 2: 남은 오류를 10% 보정
# Tree 3: 남은 오류를 10% 보정
# ...
# Tree 100: 누적 오류를 10% 보정
```

#### B. 예측 과정 (Sequential)

```
샘플 1: area=150, floor=3, ...

초기 예측:
  ŷ₀ = y의 평균값 = 872M

Tree 1 예측 (오류를 학습):
  Tree1은 (y - ŷ₀)을 예측
  Tree1 output = +50M (오류 방향)
  ŷ₁ = ŷ₀ + 0.1 × 50M = 872M + 5M = 877M

Tree 2 예측:
  남은 오류 = 850M - 877M = -27M
  Tree2 output = -27M
  ŷ₂ = ŷ₁ + 0.1 × (-27M) = 877M - 2.7M = 874.3M

Tree 3 예측:
  남은 오류 = 850M - 874.3M = -24.3M
  Tree3 output = -24.3M
  ŷ₃ = 874.3M + 0.1 × (-24.3M) = 872.07M

...

Tree 100 예측:
  ŷ₁₀₀ = 850.2M  (최종 예측)
  
  실제값: 850M
  오류: 0.2M ✅
```

#### C. R² 계산

**Step 1: 잔차제곱합 (SS_res)**
```
100개 트리의 순차적 오류 보정으로
모든 샘플의 오류가 매우 작음

SS_res = Σ(y_i - ŷ_i)²
       = 0.2² + 0.1² + ... + ...
       = 0.04 + 0.01 + ...
       = 4,032,000,000,000  ← DT보다도 약간 크지만 여전히 작음
```

**Step 2: 전체제곱합 (SS_tot)**
```
SS_tot = 48,963,600,000,000  (동일)
```

**Step 3: R² 계산**
```
R² = 1 - (SS_res / SS_tot)
   = 1 - (4,032,000,000,000 / 48,963,600,000,000)
   = 1 - 0.0082
   = 0.9918  ✓
```

#### D. Gradient Boosting의 특징

```
✅ 강점:
  1. 순차적 오류 보정 → 높은 정확도
  2. 약한 학습기(weak learner) 앙상블 → 안정성
  3. 과적합 방지 (learning_rate < 1)

⚠️ 약점:
  1. Learning Rate가 높음 (0.1)
     → 수렴이 빨지만 부정확할 수 있음
     
  2. 각 Tree의 깊이가 얕음 (max_depth=3)
     → 복잡한 패턴 학습 제한
     
  3. Tree 수가 적음 (n_estimators=100)
     → 더 많으면 더 정확할 수 있음
```

## 🔍 왜 모델별로 R² 값이 다른가?

### 1. 함수 표현 능력 (Function Approximation)

```
Linear Regression:
  ŷ = c₀ + Σcᵢ·xᵢ
  → 1차 선형 함수만 표현 가능
  → 매우 제한적

Decision Tree:
  ŷ = if-else 체인으로 구성
  → 구간별 상수값으로 근사
  → Piecewise constant function
  → 더 복잡한 패턴 표현

Gradient Boosting:
  ŷ = Σ(αₖ × Treeₖ)
  → 순차적 트리 결합으로 오류 보정
  → 거의 임의의 함수 근사 가능
  → 매우 강력

XGBoost:
  ŷ = Σ(αₖ × Treeₖ) + 정규화 항
  → GB + 정규화
  → 가장 정교한 함수 근사
  → 과적합 방지
```

### 2. 과적합(Overfitting) vs 일반화(Generalization)

```
Linear:  과소적합 (Underfitting)
         ├─ 모델이 너무 단순
         ├─ Train R² ≈ Test R² (둘 다 낮음)
         └─ 데이터의 패턴을 못 배움

DT:      과적합 위험 (Slight Overfitting)
         ├─ 모델이 복잡할 수 있음
         ├─ Train R² > Test R² (차이 있음)
         └─ 깊이 제약(max_depth=10)으로 관리

GB:      균형잡힌 (Well-balanced)
         ├─ Learning rate < 1로 제어
         ├─ 약한 학습기 앙상블
         └─ Train ≈ Test (안정적)

XGB:     최적화됨 (Well-optimized)
         ├─ L1/L2 정규화
         ├─ 복잡도 제어 (gamma, alpha)
         └─ 가장 안정적
```

### 3. 특정 데이터 특성 학습

**우리의 데이터 특성:**
```
1. area_sqm과 market_price의 강한 비선형 관계
   → Linear: 직선으로만 근사 (큰 오류)
   → Tree: 곡선으로 근사 (작은 오류)
   
2. Feature 상호작용 있음
   예: area와 floor의 결합 효과
   → Linear: 학습 불가
   → Tree: 자동 학습
   
3. 국소적 패턴 존재
   예: 특정 가격대에서만 유효한 규칙
   → Linear: 전역 규칙만 학습
   → Tree: 국소적 규칙 학습 가능
```

## 📊 실제 계산 예시 (작은 데이터셋)

### 데이터셋: 5개 샘플

```
y (실제값):        [100, 200, 150, 250, 180]
ȳ (평균):         = 176

선형 모델 예측:   [110, 190, 140, 260, 170]
트리 모델 예측:   [100, 200, 150, 250, 180]
```

### Linear Regression R² 계산

```
SS_res = (100-110)² + (200-190)² + (150-140)² + (250-260)² + (180-170)²
       = 10² + 10² + 10² + 10² + 10²
       = 100 + 100 + 100 + 100 + 100
       = 500

SS_tot = (100-176)² + (200-176)² + (150-176)² + (250-176)² + (180-176)²
       = 76² + 24² + 26² + 74² + 4²
       = 5,776 + 576 + 676 + 5,476 + 16
       = 12,520

R² = 1 - (500 / 12,520)
   = 1 - 0.0399
   = 0.9601  ← 선형도 이 경우엔 높음 (완전 선형 데이터)
```

### Decision Tree R² 계산

```
SS_res = (100-100)² + (200-200)² + (150-150)² + (250-250)² + (180-180)²
       = 0 + 0 + 0 + 0 + 0
       = 0

SS_tot = 12,520  (동일)

R² = 1 - (0 / 12,520)
   = 1.0000  ← 완벽한 예측
```

| 요소 | Linear | DT | GB | XGB |
|------|--------|----|----|-----|
| 함수 표현 능력 | 1차 선형 | 계단형 | 부드러운 곡선 | 최적화 곡선 |

- **XGB > GB > DT**: 정규화 및 최적화의 정도 차이
