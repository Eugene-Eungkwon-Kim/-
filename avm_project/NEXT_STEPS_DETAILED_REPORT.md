### **2단계: Cloud Run 배포** (필수)

#### 📌 배경

현재 상태:
- ✅ Docker 환경 준비 (Dockerfile 제공)
- ✅ 로컬 테스트 완료
- ⏳ Cloud Run 배포 대기

#### 🎯 작업 내용

**A. 사전 준비** (1일)

```bash
# 1. GCP 프로젝트 생성
gcloud projects create avm-project
gcloud config set project avm-project

# 2. 필요한 API 활성화
gcloud services enable \
  run.googleapis.com \
  cloudbuilder.googleapis.com \
  containerregistry.googleapis.com

# 3. 서비스 계정 생성
gcloud iam service-accounts create avm-deployer
```

**B. 보안 설정** (1일)

```bash
# 1. 환경 변수를 Secret Manager에 저장
gcloud secrets create avm-api-key \
  --data-file=<(echo -n "YOUR_API_KEY")

# 2. 권한 부여
gcloud secrets add-iam-policy-binding avm-api-key \
  --member=serviceAccount:avm-deployer@avm-project.iam.gserviceaccount.com \
  --role=roles/secretmanager.secretAccessor
```

**C. Docker 빌드 및 배포** (30분)

```bash
# 1. 이미지 빌드
docker build -t gcr.io/avm-project/avm-server:v1.0 .

# 2. 레지스트리에 푸시
docker push gcr.io/avm-project/avm-server:v1.0

# 3. Cloud Run에 배포
gcloud run deploy avm-server \
  --image gcr.io/avm-project/avm-server:v1.0 \
  --platform managed \
  --region asia-northeast1 \
  --memory 2Gi \
  --cpu 1 \
  --timeout 300 \
  --set-env-vars DATA_GO_KR_API_KEY=<API_KEY> \
  --allow-unauthenticated
```

**D. 배포 후 검증** (30분)

```bash
# 1. 배포 상태 확인
gcloud run services list
gcloud run services describe avm-server --region asia-northeast1

# 2. API 엔드포인트 테스트
SERVICE_URL=$(gcloud run services describe avm-server \
  --region asia-northeast1 --format 'value(status.url)')

# 3. 헬스 체크
curl $SERVICE_URL/health

# 4. 대시보드 접속
echo "대시보드: $SERVICE_URL/dashboard"

# 5. API 테스트
curl -X POST $SERVICE_URL/predict \
  -H "Content-Type: application/json" \
  -d '{
    "property": {
      "area_sqm": 102.5,
      "year_built": 2010,
      ...
    }
  }'
```

#### 📊 배포 설정

```yaml
리소스:
  메모리: 2GB
  CPU: 1개
  시간 제한: 300초

네트워크:
  리전: asia-northeast1 (서울)
  공개: 인증 없음 (필요시 추가)

모니터링:
  로그: Cloud Logging (자동)
  메트릭: Cloud Monitoring (자동)
```
