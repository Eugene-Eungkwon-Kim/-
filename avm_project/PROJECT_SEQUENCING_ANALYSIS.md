## 2. 의존성 분석

### 2.1 AVM ← VWorld 의존 여부

```
AVM (실거래 데이터 모델)
  ├─ 독립적 실행 가능: ✅ YES
  ├─ VWorld 없이 배포: ✅ YES (현재 상태)
  └─ VWorld 통합 후: ✅ feature 추가로 정확도 향상

VWorld 멀티레이어 → AVM 통합
  ├─ AVM 배포 선행 필요: ❌ NO (병렬 가능)
  ├─ AVM 모델 활용: ✅ PNU를 통한 feature join
  └─ 독립적 개발: ✅ YES (14개 layer DB)
```

