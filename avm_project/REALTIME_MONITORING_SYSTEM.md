**증상**:
```
⚠️ KOREA_API_KEY 환경변수 미설정 (48시간 초과)
```

**대응**:
```
1. 백업 계정으로 신청된 키 사용
2. 또는 07-05 수집 01:00으로 연기
3. Slack에 즉시 보고
```

### **Issue 2: 데이터 품질 저하 (확률 10%)**

**증상**:
```
⚠️ 수집 성공률 <95% (오류 5건 초과)
```

**대응**:
```
1. 로그 분석: tail -f data/fetch_transactions_parallel.log
2. SGG 코드 또는 API 파라미터 재검증
3. 필터링 강화 (이상값 기준)
4. 재시도 (자동 재시도는 3회까지)
```

### **Issue 3: 모델 성능 미달 (확률 15%)**

**증상**:
```
⚠️ MAPE >10.5% (목표 <10.5%)
```

**대응**:
```
1. 특성 공학 재검토 (추가 파생 특성)
2. 하이퍼파라미터 재튜닝
3. 데이터 정제 강화
4. 최악: 기존 모델 (R²=0.949) 유지 후 Phase 2에서 개선
```
