## 🚨 Linear Regression 부적합 이유

### 기본 통계

```

3% 이내 달성:  5.7% (극도로 낮음)
```

### 가격대별 괴리율

```
~400만원:        15.54%  ❌
400~600만원:      8.52%  ❌
600~800만원:     28.14%  ❌ 최악
800~1000만원:    20.74%  ❌
1000~1500만원:   14.55%  ❌
1500만원~:       12.19%  ❌
```

### 왜 실패했는가?

```
1. 비선형 데이터
   선형 모델: y = c₀ + c₁·x₁ (일차식)
   실제:      y = f(x) (복잡한 곡선)
   → 직선으로 곡선을 근사할 수 없음

2. Feature 상호작용 무시
   실제: area가 크고 floor가 많으면 시너지 효과
   선형: 각 feature의 영향이 독립적

3. 극단값의 영향
   최대 오차: 833,540,020 원 (실거래가의 97% 오류!)
   → 선형 회귀선이 극단값에 왜곡됨
```
