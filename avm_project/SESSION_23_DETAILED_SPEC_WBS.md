## 1. Track E: 필지-지번 복원 및 토지 매칭 (1순위)

### 목표
RTMS 토지 거래 데이터(152,007건)의 마스킹된 지번을 국가공간정보포털 API(국토지리정보원)를 통해 복원하여 NPL 토지 물건과의 T1/T2 매칭을 가능하게 한다. 현재 NO-GO 상태를 **70%+ 매칭률**의 GO 상태로 전환.

### 기술 원리

```
RTMS 토지 거래 기록 (152,007건)
├─ lawd_cd (지역코드): "11110" 등
├─ jibun (마스킹됨): "2*", "*" 등
├─ address_text: "종로구 인의동 2*"
└─ address_sido/sigungu: 지역명

↓ 국가공간정보포털 API (NSDI OpenAPI)
  입력: 지역코드 + 좌표 또는 지번 일부 + 필지 크기 정보

중간 단계: 필지고유번호(PNU) 획득
  PNU = lawd_cd(8) + 필지번호(4)

↓ 토지이음(Land Link Portal) CSV/API 역매칭
  PNU ↔ 실제 지번 매핑 테이블

출력: 복원된 실제 지번
└─ NPL 토지 물건(jibun_norm) 정확 매칭(T1)
```

## 2. Track D: 극단치 분석 및 낙찰가율 모델 재설계 (2순위, 병렬 가능)

### 목표
Session 22에서 발견한 극단치 2건(낙찰가율 0.01, APE 5000%)의 원인을 파악하고, leave-one-out 단순평균(14.26%)을 능가하는 로버스트 모델(목표: 12% 이상)을 재설계한다.

### 발견된 극단치 (재확인)

|----|----|---------|---------|-----|---------|

### 명세

**신규 스크립트**: `scripts/phase7_d_outlier_analysis.py`, `scripts/phase7_d_robust_hammer_model.py`

**Step D.1: 극단치 원본 데이터 조사 (1시간)**

입력: Track C 검증셋 CSV (id=146, 396 포함)

조사 항목:
- `onbid_auction_results` 원본 레코드 확인 (address_raw, bid_round, final_result 등)
- 해당 물건의 경매 이력 (몇 회차 낙찰인가? 유찰 후 강제 낙찰?)
- 감정가 출처 (공식 감정사 감정인가? 기준가 오류?)
- 거래 월 (경기 침체, 재정 위기 기간?)

산출: `results/phase7_d_outlier_investigation.md`

**Step D.2: 모델 재설계 (2시간)**

기존 문제: 지역×자산유형 세분화가 실패 (세그먼트당 표본 부족 → 노이즈 증가)

새로운 접근: **로버스트 통계 기반**

| 방식 | 알고리즘 | 예상 성능 | 비고 |
|------|---------|---------|------|
| 전역 중앙값 | median(hammer_rate) | ~14% (baseline) | 극단치 영향 최소 |
| 트림드 평균 | mean(hammer_rate[~outlier]) | 12-13%? | 하위/상위 5% 제외 |
| Huber Regression | 손실함수: Huber loss (극단치 가중 감소) | 12%? | XGBoost Huber 객체 함수 |
| Quantile Regression | q=0.5 (중앙값 회귀) | 12-13%? | 각 지역/자산유형별 분위수 |

선택: **Huber Regression (XGBoost 내장)** 또는 **Quantile Regression q=0.5**
- 이유: 극단치의 영향을 부드럽게 감소시켜 과적합 방지, 표본 작은 상황에 적합

구현:
```python
# XGBoost with Huber objective
xgb_model = xgb.XGBRegressor(
    objective='reg:pseudohuber',  # Huber 손실
    huber_slope=1.0,
    max_depth=4,
    learning_rate=0.05,
)

# 또는 Quantile Regression (median)
qr_model = xgb.XGBRFRegressor(
    objective='reg:quantilizedregression',
    quantile_alpha=0.5,  # 중앙값
)
```

산출: 모델 객체, 예측값

**Step D.3: 극단치 제외/포함 비교 (30분)**

| 버전 | n | MAPE | 비고 |
|------|---|------|------|
| 극단치 포함 (기존) | 43 | 281-339% | mean(MAPE) 왜곡 심함 |
| 극단치 제외 (baseline) | 41 | 14.26% | leave-one-out 단순평균 |
| 로버스트 모델 | 43 | **12% 이상?** | Huber/Quantile 회귀 |

산출: `results/phase7_d_model_comparison.md`

## 3. Track F: NPL 평가보고서 학습 및 출력 형식 설계 (2순위, 병렬 가능)

### 목표
실제 NPL 평가보고서(우리F&I 엑셀 양식, 샘플 데이터)를 학습하여 **3가지 가격 항목(예상법사가, 거래가능시세, 예상낙찰가격)**의 산출 방식을 이해하고, Session 23-24의 최종 시스템 출력 형식을 설계한다.

### 명세

**입력 자료** (F:\NPL전례\ 폴더에서 확인 필요):
- `우리F&I 엑셀 양식.xlsx` (공식 평가보고서 템플릿)
- `정밀샘플.xlsx`, `약식(구분건물) 샘플.xlsx` (샘플 데이터)

**Step F.1: 우리F&I 양식 분석 (1시간)**

분석 항목:
1. **3가지 가격 항목의 위치 및 계산식**
   - H27: 예상법사가 (= 감정평가사 감정가)
   - J27: 거래가능시세 (= 평당거래시세 × 총평수)
   - L27: 예상낙찰가격 (= 평당낙찰시세 × 총평수)
   - N27: 낙찰가율 (= L27 / H27)

2. **각 항목의 데이터 원천**
   - 예상법사가: 감정평가사 의견서
   - 거래가능시세: RTMS 실거래가 (시세 마트)
   - 예상낙찰가격: 과거 낙찰가율 × 감정가 또는 직접 예측

3. **구분건물 vs 약식 차이**
   - 아파트: 개별 호실 + 공용부분 분리 계산
   - 상가/토지: 단순 계산

산출: `results/phase7_f_npl_report_structure.md` (양식 분석 문서)

**Step F.2: 샘플 데이터로 역산 검증 (1시간)**

샘플에서:
- H27(예상법사가) 값
- J27(거래가능시세) 값
- L27(예상낙찰가격) 값

→ 실제 계산 확인:
```
예상낙찰가격(L27) = 평당낙찰시세 × 총평수
            또는 = 예상법사가(H27) × 낙찰가율(역산)
```

산출: 검증 결과 문서, 계산식 확정

**Step F.3: 우리 모델과의 연결 설계 (1시간)**

현재 우리 모델의 출력:
- 그라운딩 시세 추정치 (MAPE 9.40%, 감정가 대비)
- 낙찰가율 예측 (MAPE 14.26%, 미검증)

NPL 양식과의 매핑:
```
우리 시스템 출력                NPL 보고서 항목
├─ 감정가(DB에서 조회)      → H27 예상법사가
├─ RTMS 시세 추정(그라운딩)  → J27 거래가능시세
├─ 낙찰가율 예측(D 모델)     × 감정가 → L27 예상낙찰가격
└─ 신뢰도 분류(C 모델?)       → 평가 신뢰도
```

산출: `results/phase7_f_output_format_design.md` (최종 출력 스펙)

### 완료 기준
