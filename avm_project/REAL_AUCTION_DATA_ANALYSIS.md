## ⚠️ **III. 경매가가 시장가보다 낮은 이유**

```
【 경매 특성 】

1️⃣ 차주 부실 경영
   - ㈜한국전파시험연구소: 부도/부실 경영 추정
   - 은행 담보 처분으로 강제 경매
   - 조사시점: 미가동 상태

2️⃣ 기계설비 미가동
   - 경매가 기준: 미가동 상태 (4~8%)
   - 시장가 기준: 가정상 가동 (12~30%)
   - 차이: 미가동 상태이므로 경매가 훨씬 낮음

3️⃣ 강제 처분의 특성
   - 경매는 강제 처분 (빠른 매각 필요)
   - 시장가는 협상 가능 (최고 수준)
   - 따라서 경매가 < 시장가

4️⃣ 기술력/재가동성 불확실
   - 전파 시험 연구소 특수 시설
   - 기계 재가동 비용 미포함
   - 산업용 특수 건물 (일반 공장과 다름)

【 결론 】

경매 낙찰가: 44.78억원 (낮음) - 강제 처분
시장가: 26.29억원 (중간) - 협상 가능
추정가: 20.01억원 (보수적) - 안정적 평가

역설: A(경매) > M(시장가) > E(추정가)
      44.78억 > 26.29억 > 20.01억

→ 매우 특이한 평가 구조!
→ 경매가가 시장가보다 높음
→ 이는 기계 미가동의 영향
```
