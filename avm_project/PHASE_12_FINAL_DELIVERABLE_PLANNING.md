## 💡 구현 기술 선택

### Excel 생성 도구
```
✅ openpyxl (Python)
   • 장점: Pure Python, 설치 간단
   • 사용: 셀 값, 포맷팅, 스타일
   • 코드: 15-20줄
```

### PDF 생성 도구
```
Option 1: reportlab (Python) ✅ 권장
  • 장점: Python, 프로그래매틱 생성
  • 단점: 세밀한 레이아웃 어려움
  
Option 2: PyPDF2 (Python)
  • 장점: PDF 조작
  • 단점: 생성에 약함
  
Option 3: 템플릿 기반 (Markdown → PDF)
  • 도구: pandoc, weasyprint
  • 장점: 높은 자유도
  • 단점: 설정 복잡
  
추천: HTML → PDF (weasyprint 또는 브라우저 API)
  • 가장 자유도 높음
  • 스타일 제어 가능
  • 최종 품질 최고
```
