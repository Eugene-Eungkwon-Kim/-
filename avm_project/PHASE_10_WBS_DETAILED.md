10.1.1.4: 정확도 계산 엔진
```
계산식:
- 절대 오차: |예측값 - 실제값|
- 상대 오차율: |예측값 - 실제값| / 실제값 × 100
- 범위 검증: ±5% 범위
- 정확도 등급: HIGH(≤2%), MEDIUM(2-5%), LOW(>5%)

구현:
def calculate_accuracy(predicted, actual):
    abs_error = abs(predicted - actual)
    error_rate = (abs_error / actual) * 100
    if error_rate <= 2:
        level = "HIGH"
    elif error_rate <= 5:
        level = "MEDIUM"
    else:
        level = "LOW"
    return {
        "abs_error": abs_error,
        "error_rate": error_rate,
        "level": level
    }
```

10.1.2.3: NPS 계산
```
NPS = (추천자 % - 비추천자 %) × 100

구분:
- 추천자 (Promoters): 9-10점 (%)
- 중립자 (Passives): 7-8점 (무시)
- 비추천자 (Detractors): 0-6점 (%)

목표: NPS ≥ 50
산업 평균: 40-50
우수: 60 이상

계산식:
def calculate_nps(scores):
    promoters = len([s for s in scores if s >= 9])
    detractors = len([s for s in scores if s <= 6])
    total = len(scores)
    nps = ((promoters - detractors) / total) * 100
    return nps
```

```
- 도구: scikit-learn 또는 PyTorch
- 기대 효과:
  - 모델 크기: 50% 감소
  - 추론 속도: 2배 향상
  - 정확도 손실: < 0.5%

결합 효과:
- 최종 모델 크기: 원본 대비 62.5% 감소
- 최종 추론 속도: 6배 향상
```
