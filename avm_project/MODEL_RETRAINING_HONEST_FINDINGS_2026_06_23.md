## 🔴 핵심 결론 (먼저)

현재 학습 데이터로는 **AVM(자동 감정가) 모델이 작동하지 않습니다.**
7개 모델을 실제로 재학습한 결과, **모든 모델의 R²가 음수**였습니다.
이는 "평균값을 그냥 찍는 것보다 못하다"는 의미입니다.

원인은 모델·인프라가 아니라 **데이터**입니다. 현재 학습 파일은
feature와 가격(target) 사이에 **실질적 상관관계가 전혀 없는 합성 데이터**입니다.

따라서 **데이터베이스 로드(Track A)나 클라우드 배포(Track C)를 진행해도
의미 없는 예측을 하는 시스템을 배포하게 됩니다.** 진짜 데이터 확보가 선행되어야 합니다.

## 📊 실제 측정 결과

**데이터:** `cleaned_real_estate_combined_20260617.csv` (3,000행, 19 feature + market_price)
이 파일은 기존 모델 스키마(`models/feature_schema.json`)와 완전히 일치하는,
결측치 0의 유일한 일관된 데이터셋입니다. Train 2,400 / Test 600으로 분할.

| 모델 | R² | RMSE | MAE | MAPE |
|------|-----|------|-----|------|
| Linear Regression | **-0.0034** | 13,266 | 11,514 | 78.6% |
| Random Forest | **-0.0349** | 13,472 | 11,668 | 79.4% |
| Gradient Boosting | **-0.0558** | 13,608 | 11,751 | 79.6% |
| Ensemble (Voting) | **-0.0677** | 13,684 | 11,788 | 80.3% |
| LightGBM | **-0.1209** | 14,021 | 11,927 | 81.1% |
| XGBoost | **-0.1581** | 14,251 | 12,191 | 82.4% |
| Decision Tree | **-0.2673** | 14,909 | 12,359 | 81.1% |

**목표 달성(R² ≥ 0.85): 0 / 7 모델**

> R² 해석: 1.0 = 완벽, 0.0 = 평균값 예측과 동일, 음수 = 평균값보다 못함.
> 평균 오차율(MAPE)이 ~80%라는 것은 예측이 사실상 무작위라는 뜻입니다.

## 🔬 근본 원인: 데이터에 신호가 없음

feature와 target(market_price) 간 상관계수를 측정한 결과:

```
최대 상관계수: 0.0388 (outstanding_debt)
대부분의 feature: 0.001 ~ 0.02
면적(area_sqm) ↔ 가격:        0.0028
건축년도(year_built) ↔ 가격:  0.0012
```

정상적인 부동산 데이터라면 면적·위치·연식이 가격과 강한 상관(보통 0.5~0.8)을
가져야 합니다. 그러나 이 데이터는 **최대 상관이 0.04**로, 가격이 feature와
독립적으로 무작위 생성되었음을 보여줍니다.

**어떤 모델·하이퍼파라미터 튜닝·앙상블로도 존재하지 않는 관계를 학습할 수 없습니다.**

## ⚠️ 기존 성능 보고서와의 차이 (반드시 짚고 넘어갈 점)

기존 문서(`PERFORMANCE_BENCHMARK_REPORT.md` 등)의 "R² 0.88", "목표 대비 166배"
같은 수치는 **추론 속도(latency)** 를 측정한 것이지, **예측 정확도(R²)** 를
측정한 것이 아니었습니다.

- 측정했던 것: 모델이 숫자를 얼마나 **빨리** 반환하는가 (0.6ms)
- 측정하지 못했던 것: 그 숫자가 **맞는가** (R²)

빠르게 반환되는 틀린 값은 여전히 틀린 값입니다.
이번에 처음으로 **정확도**를 실제로 측정했고, 그 결과가 위와 같습니다.

사용자가 언급한 실제 데이터 소스를 확보·연동해야 모델이 의미를 가집니다:

- 부동산원 RTECH — 시세·시장 지표

이 데이터로 다시 학습하면 feature-가격 상관이 살아나고, 그때 비로소
R² 목표·성능 검증·배포 논의가 의미를 가집니다.
