스크립트 현황

  • run.py

    통합 실행기

    아래 네 스크립트를 서브명령 하나로 실행합니다. 각 스크립트의 옵션을 그대로 전달합니다.

    $ python run.py iphone     ~/iPhone_내보내기 ~/정리결과
$ python run.py migrate    --android ./정리결과
$ python run.py organize   ~/phone_files ./정리결과
$ python run.py realestate --lawd 11680 --start 202401 --end 202406
    서브명령
    organize · migrate · iphone · realestate

  • cleanup.py

    저장공간 정리

    용량을 어디서 잡아먹는지 분석하고, 중복·캐시를 지워 공간을 회수합니다. 기본은 읽기 전용 분석입니다.

    $ python cleanup.py ~/정리결과                  # 분석만
$ python cleanup.py ~/정리결과 --apply          # 실제 삭제
$ python cleanup.py --android                   # 기기 용량 리포트
    분석
    카테고리별 용량 비중 · 상위 폴더 · 대용량 파일 · 중복 그룹 · 캐시 · 빈 폴더
    중복 탐지
    같은 크기 파일만 해시하는 2단계 방식 — 전체 해시보다 빠름
    원본 보존
    DCIM 등 카메라 폴더의 오래된 파일을 유지, (1)·_copy·사본 패턴을 삭제 후보로
    옵션
    --apply · --top · --min-size · --report · --android
    출력
    cleanup_report.json

  • iphone_migrate.py

    iPhone 13 Pro 전용

    HEIC/HEIF를 지원하고, 같은 이름의 HEIC+MOV 쌍을 Live Photo로 자동 감지해 별도 폴더로 분리합니다.

    분류
    사진 · 라이브포토 · 동영상 · 슬로모션 · 타임랩스 · 음악 · 문서 · 압축파일 · 기타
    패턴
    SloMo → 슬로모션, TimeLapse · IMG_E#### → 타임랩스
    옵션
    --dry-run
    출력
    iphone_migration_report.json (카테고리별 통계)

  • migrate.py

    Android · 로컬 폴더

    ADB로 기기에 직접 연결해 파일을 끌어오거나, 기존 백업 폴더를 정리합니다.

    ADB 경로
    DCIM · Pictures · Movies · Music · Download · Documents · WhatsApp · Telegram · KakaoTalk
    분류
    사진 · 동영상 · 음악 · 문서 · 압축파일 · APK · 기타
    옵션
    --android · --source · --dry-run
    출력
    migration_report.json

  • organize.py

    기본 파일 정리

    기기 종류를 가리지 않는 기본 정리기. 종류별 + 날짜별로 나누고 파일명을 통일합니다.

    구조
    카테고리/YYYY/MM/
    파일명
    YYYYMMDD_HHMMSS_원본이름.확장자
    날짜
    EXIF 촬영일 우선, 없으면 파일 수정일 (Pillow 설치 시)
    옵션
    --dry-run

  • fetch_realestate.py

    부동산 실거래가 · Loan4u / AVM

    국토교통부 아파트 매매 실거래가 API(data.go.kr)를 지역·기간별로 조회해 CSV로 저장합니다.

    컬럼
    시군구코드 · 법정동 · 단지명 · 지번 · 전용면적 · 층 · 건축년도 · 거래일자 · 거래금액 · 해제여부 · 거래유형
    옵션
    --lawd · --start · --end · --key · --out · --delay
    인증키
    --key 또는 환경변수 DATA_GO_KR_KEY (data.go.kr 디코딩 키)
    출력
    utf-8-sig CSV — Excel에서 한글 깨짐 없음

실행 전 확인

  • 원본 파일은 복사가 아니라 이동됩니다. 반드시 미리 백업하세요.
  • 중복 파일은 MD5 해시로 감지해 원본만 남기고 삭제합니다.
  • 먼저 --dry-run으로 결과를 확인하는 것을 권장합니다.
